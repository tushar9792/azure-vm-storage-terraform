

\# Azure VM and Storage Infrastructure using Terraform



\## Project Status

In Progress



\## Project Overview

This project demonstrates the automated deployment of

Azure infrastructure using Terraform.



The objective is to build a secure cloud environment

for a small business application.



\## Technologies

\- Microsoft Azure

\- Terraform

\- Azure CLI

\- Ubuntu Linux

\- Microsoft Entra ID

\- Azure Virtual Network

\- Network Security Groups

\- Azure Blob Storage

\- Git and GitHub



\## Planned Infrastructure



1\. Azure Resource Group

2\. Virtual Network and Subnet

3\. Network Security Group

4\. Ubuntu Linux Virtual Machine

5\. Managed Disk

6\. Azure Storage Account

7\. Blob Container

8\. VM Managed Identity

9\. Azure RBAC

10\. Monitoring and testing



\## Security Implementation

\- Secure SSH access

\- Network traffic restrictions

\- HTTPS-only storage access

\- Managed Identity authentication

\- Least-privilege Azure RBAC



\## Deployment

Terraform will be used to provision and manage

the Azure infrastructure.



\## Testing

Deployment, connectivity, storage access and

security configurations will be verified.
